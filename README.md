This is a WarioWare-style game, meaning there are many small minigames

The first minigame is a platformer with a knight controlled by the arrow keys and space
you try to collect coins before the timer runs out.

The second minigame is a clicker where you have to click all of the coins before the timer runs out

The last minigame is a minigame where you have to catch falling coins, and you have to catch them before the timer runs out.

There is also a surprise at the win screen!

Have fun playing!
